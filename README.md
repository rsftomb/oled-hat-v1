0.96in Waveshare OLED Hat V1 – README 

OLED-Hat-V1 is a Raspberry Pi monitoring tool designed for multi-screen OLED HATs. It displays real-time system stats including:

    CPU load
    RAM usage
    Temperature (°F or °C)
    WiFi networks detected (current + unique)
    Bluetooth devices detected (current + unique)
    Uptime
    USB/5V Input voltage (where supported)
    Auto-updates from Git repo and is designed for continuous 24/7 operation.

Features

    Supports multi-display Waveshare OLED HATs
    Auto-update on boot (Git pull)
    Auto-start via systemd
    Clean modular Python structure
    Zero configuration after installation
